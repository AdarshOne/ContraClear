# ContraClear

Reads signed contracts and tells you, in plain English, what you owe, to whom and when. Every item shows its exact quote and page. Free, open source, local-first. Not legal advice.

```bash
npm install
npm run dev
```

Your contracts are read in the browser and stored in an encrypted vault on your device. Nothing is uploaded.

See `CLAUDE.md` for the build brief and current build status, `docs/final-design-prompt.md` for the requirements, and `design/` for the design boards.
